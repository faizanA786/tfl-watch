# TfL Watch

![img](https://i.imgur.com/mAw21OA.png)

TfL Watch is a Chrome browser extension that displays live Transport for London arrival data across all supported modes, along with current service disruptions.

It provides a quick way to check station arrivals and disruptions directly from your browser.

## Features

- Live arrival times for selected stations
- Support for multiple TfL transport modes (Tube, Overground, DLR, Bus, etc.)
- Real-time disruption information
- Background auto-refresh

## Tech Stack

- Backend: JavaScript
- Frontend: Plain HTML, CSS
- APIs: Chrome Extension APIs, TFL Unified API

## Usage
This extension is currently not published on the chrome web store. However, you may still use it locally by cloning this repository and loading the extension folder unpacked in chromes extension page, with developer mode enabled.
